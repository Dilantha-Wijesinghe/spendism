## [0.1.0] - 2026-05-25

### Added
- Initial release of Spendism
- Dashboard with net balance, monthly summary, budget ring progress, recent transactions, and 6-month income vs expense trend chart
- Transaction management: add, edit, delete, search, and filter by type, category, and time period
- Budget management: set monthly or yearly limits per category with visual progress tracking and overspend alerts
- Reports view: spending breakdown by category and time-range trend charts
- Settings: currency selection, category management, data export/import (CSV + JSON), and data reset
- Multi-currency support: USD, EUR, GBP, LKR, AUD, CAD, INR, JPY
- localStorage persistence with schema versioning
- Mobile-first responsive UI
